## 🚀 Featured Projects

### ⭐ InterviewAI — AI-Powered Interview Preparation

An AI-powered interview preparation platform that transforms resumes into personalized interview practice, evaluates answers, and helps candidates identify skill gaps.

- Generates technical, behavioral, and coding questions from resumes.
- Supports text and voice mock interviews, dynamic follow-ups, and AI-based feedback.
- Includes ATS resume analysis, readiness scoring, learning roadmaps, and interview analytics.
- Provides authentication and a responsive SaaS-style interface.

**Focus:** LLMs · Generative AI · Full-Stack Development · Voice AI

### ⚡ PowerPulse — Energy Management System

A full-stack energy monitoring application for tracking meter-level and line-level electricity consumption with interactive analytics and automated alerts.

- Visualizes daily, weekly, and monthly consumption using React and Recharts.
- Provides authenticated, role-based access through ASP.NET Core REST APIs and JWT.
- Uses Entity Framework Core, SQL Server, and a repository/service architecture.
- Detects abnormal energy usage with scheduled background services and configurable thresholds.

**Tech:** React · ASP.NET Core Web API · SQL Server · Entity Framework Core · Recharts
